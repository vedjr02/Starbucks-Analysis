# Starbucks Sales Analysis

Premium business analytics case study landing page — built to present daypart revenue, loyalty behavior, and product-mix findings like a consulting deliverable.

## Stack

- **Next.js** + Tailwind CSS
- **Magic UI** — number ticker, blur fade, marquee, border beam, shine border, text reveal, scroll progress
- **ReUI** — interactive methodology stepper
- **GSAP** + ScrollTrigger
- **Recharts**

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Project structure

```
src/
  app/                  # Next.js app router
  components/
    case-study/         # Page sections
    reui/               # ReUI stepper
    ui/                 # Magic UI + shadcn primitives
  lib/case-data.ts      # Case study content & chart data
```
